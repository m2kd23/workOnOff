[업무 이어하기 프로그램 (WorkOnOff) 사용자 매뉴얼]

본 프로그램은 퇴근 전 사용자가 작업하던 문서들과 폴더를 기억해 두었다가, 다음 날 클릭 한 번으로 전날의 업무 환경을 그대로 다시 열어주는 업무 효율화용 경량 프로그램입니다.

--------------------------------------------------
■ 1. 프로그램 실행 방법
--------------------------------------------------
1. 배포받은 폴더 내의 [WorkOnOff.exe] 파일을 더블클릭하여 실행합니다.
   ※ 본 프로그램은 컴퓨터에 설치되지 않는 '무설치(Portable)' 프로그램입니다. 
   ※ 일반 권한으로 작동하므로 보안 경고나 관리자 승인 창이 뜨지 않습니다.
   ※ 첫 실행 시 바탕화면에 [WorkOnOFF 업무 바로 이어하기] 바로가기가 생성됩니다. 이후 [Ctrl + Shift + 1]을 누르면 프로그램을 실행하며, 이미 열려 있으면 기존 창을 앞으로 표시합니다.

--------------------------------------------------
■ 2. 퇴근 전: 오늘 하던 업무 저장하기
--------------------------------------------------
1. 퇴근하기 직전, [WorkOnOff.exe]를 실행합니다.
2. 화면 상단의 "현재 열려 있는 업무 목록"에 현재 열려 있는 한글(HWP/HWPX), 엑셀, PowerPoint, PDF, 메모장, 탐색기 폴더와 브라우저의 현재 탭 등이 자동으로 표시됩니다.
3. 내일 아침에 다시 열고 싶은 파일이나 폴더의 체크박스(☑)를 선택합니다.
   - [전체 선택] 또는 [전체 해제] 버튼을 활용할 수 있습니다.
   - 목록에 나타나지 않은 파일이나 폴더는 [파일 추가] / [폴더 추가] 버튼을 눌러 직접 추가할 수 있습니다.
   - 자동으로 찾지 못한 웹페이지는 [브라우저 URL 추가]에서 주소를 붙여 넣어 추가할 수 있습니다. 다음 날에는 저장 당시 브라우저를 우선 사용해 해당 주소를 엽니다.
   - 불필요한 항목은 마우스로 선택한 후 [목록에서 삭제] 버튼을 눌러 목록에서 지울 수 있습니다.
4. "업무 메모" 입력란에 내일 이어할 업무의 주요 내용을 적어줍니다.
   (예: "AI 결과보고서 5페이지 예산 분석부터 작성 계속")
5. 화면 중앙의 [다음날 하기] 버튼을 누릅니다.
6. "현재 업무 X개를 저장했습니다. 프로그램을 종료하고 퇴근하셔도 됩니다." 라는 메시지가 뜨면 확인을 누르고 컴퓨터를 종료한 뒤 퇴근합니다.

--------------------------------------------------
■ 3. 다음 날 출근 후: 업무 다시 이어하기
--------------------------------------------------
1. 출근 후 컴퓨터를 켜고 [WorkOnOff.exe]를 실행합니다.
2. 화면 하단의 "최근 저장된 업무 목록"에서 전날 저장한 업무 세션을 선택합니다. (메모 내용과 날짜를 보고 확인)
3. 우측의 [업무 이어하기] 버튼을 누르거나, 해당 항목을 마우스로 더블클릭합니다.
4. 전날 열려 있던 모든 엑셀, 한글(HWP/HWPX), PowerPoint, PDF 문서, 탐색기 폴더와 저장한 웹페이지가 자동으로 한꺼번에 다시 열립니다!

--------------------------------------------------
■ 4. 기타 유용한 기능
--------------------------------------------------
▶ [현재 상태로 업데이트] 기능:
   어제 저장한 업무를 열어서 오전에 계속 작업하다가, 오후에 출장을 가거나 퇴근해야 할 때, 기존 저장된 메모 카드를 마우스로 선택한 뒤, 우측 중앙의 [현재 상태로 업데이트] 버튼을 누르면 오늘 작업 중인 최신 상태로 덮어쓰기 저장됩니다.

▶ [내용 보기] 기능:
   저장된 업무 세션을 선택하고 [내용 보기] 버튼을 누르면 세션에 들어 있는 파일 목록을 별도 창으로 볼 수 있으며, 특정 파일만 개별적으로 열거나 폴더를 열고, 또는 목록에서 개별 삭제할 수 있습니다.

▶ [삭제] 기능:
   완료되어 더 이상 이어할 필요가 없는 과거 업무 세션은 선택 후 [삭제] 버튼을 눌러 지울 수 있습니다.

--------------------------------------------------
■ 5. 주의 및 안내사항
--------------------------------------------------
- 본 프로그램은 파일 내부 문서 내용이나 수정한 글자를 임시 저장해 두는 '자동 저장' 기능이 아닙니다. 파일의 저장 위치(경로)를 기억해 두었다가 다시 열어주는 프로그램이므로, 퇴근 전 반드시 작업하던 문서들의 [저장](Ctrl+S) 버튼을 먼저 눌러 수동 저장하신 후 퇴근하시기 바랍니다.
- 저장했던 파일의 이름을 바꾸거나 다른 폴더로 이동한 경우, 이어하기 클릭 시 해당 파일은 열리지 않고 "파일을 찾을 수 없습니다" 경고가 표시됩니다. 이 경우 나머지 정상적인 다른 파일들은 문제없이 모두 정상적으로 열립니다.
- 사내 보안 프로그램(DRM)으로 암호화된 파일도 본 프로그램을 통해 문제없이 다시 복원하여 열 수 있습니다. (내부 보안 규정을 위반하거나 변조하지 않습니다.)
