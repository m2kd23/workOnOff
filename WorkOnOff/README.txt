[WorkOnOff - 경량 업무 이어하기 프로그램]

퇴근 시 열려 있는 여러 문서(한글, Excel, PDF 등)와 폴더 작업 환경을 기억해 두었다가, 다음 날 클릭 한 번으로 모든 작업을 그대로 복원할 수 있는 Windows용 경량 휴대용(Portable) 유틸리티입니다.

--------------------------------------------------
■ 주요 기능
--------------------------------------------------
- 열린 업무 자동 탐색: Excel, Word, PowerPoint, 한글(HWP/HWPX), PDF, 텍스트(TXT/CSV), Windows 탐색기 폴더와 브라우저의 현재 탭 주소 자동 수집
- 브라우저 URL 직접 추가: 자동 수집되지 않은 탭도 웹 주소를 추가해 다음 날 다시 열기
- 선택적 저장: 수집된 파일/폴더 중 복원할 항목만 선택 가능
- 업무 메모 작성: 세션별로 간단한 한 줄 메모를 입력하여 직관적인 업무 구별 지원
- 다음날 하기(세션 저장): 현재 작업 세션을 로컬 JSON 파일로 안전하게 기록
- 업무 이어하기(일괄 실행): 저장된 목록을 원본 연결 프로그램으로 한 번에 재실행
- 현재 상태로 업데이트: 기존 세션의 내용을 오늘 작업한 최신 창 목록과 메모로 덮어쓰기 기능 지원
- 비차단 예외 처리: 파일이 이동되거나 삭제되어도 경고 알림 후 남은 정상 파일은 정상적으로 일괄 실행
- 바탕화면 바로가기 및 실행 단축키 (Ctrl+Shift+1): 첫 실행 시 바탕화면에 바로가기가 생성되며, 단축키로 프로그램을 실행하거나 이미 열린 창을 앞으로 표시합니다.

--------------------------------------------------
■ 사용 방법
--------------------------------------------------
1. 퇴근 전:
   - WorkOnOff.exe 실행
   - 자동으로 감지된 현재 열린 창 목록에서 내일 이어할 항목 확인 (필요시 파일/폴더/브라우저 URL 직접 추가 가능)
   - 업무 메모 입력 (예: "AI 교육 결과보고서 작성 중 - 정량성과 부분부터 계속")
   - [다음날 하기] 버튼 클릭
   - 저장 완료 확인 후 퇴근 (실행 중이던 문서들을 닫아도 됩니다)

2. 다음 날 출근 후:
   - WorkOnOff.exe 실행
   - 하단의 "최근 저장된 업무 목록"에서 전날 작성한 세션 선택
   - [업무 이어하기] 버튼 클릭 (또는 더블클릭)
   - 전날 열어두었던 모든 파일과 폴더가 기본 프로그램으로 즉시 실행됩니다.

--------------------------------------------------
■ 주의사항
--------------------------------------------------
※ 본 프로그램은 파일 내부 내용을 자동 저장해 주는 것이 아닙니다. 파일 경로를 기억하여 다시 여는 유틸리티이므로, 반드시 원본 문서들을 저장(Ctrl+S)하신 뒤 퇴근하시기 바랍니다.
※ 암호화 문서(DRM)도 윈도우 기본 셸 실행을 이용하므로 호환성이 양호하며 안전하게 실행됩니다.
※ 인터넷 통신이나 시스템 정보 유출이 전혀 없으므로 오프라인 내부망에서 완벽한 보안성을 제공합니다.
