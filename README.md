# WorkResume (경량 업무 이어하기 프로그램)

퇴근 시 열려 있는 여러 문서(한글, Excel, PDF 등)와 폴더 작업 환경을 기억해 두었다가, 다음 날 클릭 한 번으로 모든 작업을 그대로 복원할 수 있는 Windows용 경량 휴대용(Portable) 유틸리티입니다. 

인터넷이 완전히 차단되고 보안이 강력한 공공기관 및 기업 내부망 환경을 고려하여 100% 오프라인 동작, 무설치 배포, 제로 외부 라이브러리 의존성으로 안전하게 개발되었습니다.

---

## 1. 주요 기능
- **열린 업무 자동 탐색**: Excel, Word, PowerPoint, 한글(HWP/HWPX), PDF, 텍스트(TXT/CSV), Windows 탐색기 폴더 경로 자동 수집
- **선택적 저장**: 수집된 파일/폴더 중 복원할 항목만 선택 가능
- **업무 메모 작성**: 세션별로 간단한 한 줄 메모를 입력하여 직관적인 업무 구별 지원
- **다음날 하기(세션 저장)**: 현재 작업 세션을 로컬 JSON 파일로 안전하게 기록
- **업무 이어하기(일괄 실행)**: 저장된 목록을 원본 연결 프로그램으로 한 번에 재실행
- **현재 상태로 업데이트**: 기존 세션의 내용을 오늘 작업한 최신 창 목록과 메모로 덮어쓰기 기능 지원
- **비차단 예외 처리**: 파일이 이동되거나 삭제되어도 경고 알림 후 남은 정상 파일은 정상적으로 일괄 실행
- **전역 단축키 활성화 (Ctrl+Shift+1)**: 프로그램이 백그라운드에 켜져 있거나 최소화되어 있을 때, 작업 도중 언제라도 `Ctrl+Shift+1`을 누르면 화면 맨 앞으로 즉시 복원되어 활성화됩니다.

## 2. 사용 방법
1. **퇴근 전**:
   - `WorkResume.exe` 실행
   - 자동으로 감지된 현재 열린 창 목록에서 내일 이어할 항목 확인 (필요시 파일/폴더 직접 추가 가능)
   - 업무 메모 입력 (예: "AI 교육 결과보고서 작성 중 - 정량성과 부분부터 계속")
   - **[다음날 하기]** 버튼 클릭
   - 저장 완료 확인 후 퇴근 (실행 중이던 문서들을 닫아도 됩니다)
2. **다음 날 출근 후**:
   - `WorkResume.exe` 실행
   - 하단의 "최근 저장된 업무 목록"에서 전날 작성한 세션 선택
   - **[업무 이어하기]** 버튼 클릭 (또는 더블클릭)
   - 전날 열어두었던 모든 파일과 폴더가 기본 프로그램으로 즉시 실행됩니다.

---

## 3. 개발 및 빌드 환경
- **Target OS**: Windows 10 / Windows 11 (32비트 및 64비트 호환)
- **개발 언어**: C# (C# 5.0 호환 문법 적용)
- **프레임워크**: .NET Framework 4.8
- **컴파일러**: Windows 내장 C# 컴파일러 (`csc.exe`)
- **외부 종속성**: 0% (NuGet 패키지 및 외부 DLL 전혀 없음)

---

## 4. 빌드 방법
본 프로그램은 추가 SDK 설치나 인터넷 다운로드 없이, Windows에 기본 내장된 C# 컴파일러를 이용해 즉시 컴파일할 수 있습니다.

1. 프로젝트 소스가 위치한 폴더(`WorkResume`)로 이동합니다.
2. 명령 프롬프트(cmd)에서 `build.bat`을 실행합니다.
   ```cmd
   build.bat
   ```
3. 컴파일이 성공하면 동일 폴더에 약 40KB 크기의 단일 실행 파일인 `WorkResume.exe`가 생성됩니다.

---

## 5. 배포 방법
- 설치 과정이 필요 없는 **Portable(무설치)** 방식입니다.
- 생성된 `WorkResume.exe`와 안내를 위한 `README.txt`(또는 매뉴얼)를 단일 폴더에 넣어 사용자에게 USB 또는 내부망 공유 폴더를 통해 배포하면 됩니다.
- 사용자는 `WorkResume.exe`를 더블클릭하기만 하면 즉시 실행할 수 있습니다.
- **일반 사용자 권한(`asInvoker`)**으로 실행되어 설치나 관리자 권한 승인 창(UAC)이 뜨지 않습니다.
