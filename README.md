# WorkOnOFF 업무 바로 이어하기

`WorkOnOFF 업무 바로 이어하기`는 퇴근 시 열려 있던 문서, 폴더, 브라우저 업무 페이지를 기억해 두었다가 다음 날 클릭 한 번으로 다시 여는 Windows용 경량 휴대용(Portable) 프로그램입니다.

인터넷이 완전히 차단되고 보안이 강력한 공공기관 및 기업 내부망 환경을 고려하여 100% 오프라인 동작, 무설치 배포, 제로 외부 라이브러리 의존성으로 안전하게 개발되었습니다.

---

## 1. 주요 기능
- **열린 업무 자동 탐색**: Excel, Word, PowerPoint, 한글(HWP/HWPX), PDF, 텍스트(TXT/CSV), Windows 탐색기 폴더와 브라우저의 현재 탭 주소를 수집
- **브라우저 URL 직접 추가**: 자동 감지가 되지 않은 탭도 웹 주소를 붙여 넣어 저장하고, 다음 날 저장 당시 브라우저(없으면 기본 브라우저)로 다시 열기
- **바탕화면 바로가기·실행 단축키**: `WorkOnOff.exe`를 처음 실행하면 바탕화면에 **WorkOnOFF 업무 바로 이어하기** 바로가기를 만들고, `Ctrl + Shift + 1`로 실행하거나 기존 창을 활성화
- **선택적 저장**: 수집된 파일/폴더 중 복원할 항목만 선택 가능
- **업무 메모 작성**: 세션별로 간단한 한 줄 메모를 입력하여 직관적인 업무 구별 지원
- **다음날 하기(세션 저장)**: 현재 작업 세션을 로컬 JSON 파일로 안전하게 기록
- **업무 이어하기(일괄 실행)**: 저장된 목록을 원본 연결 프로그램으로 한 번에 재실행
- **현재 상태로 업데이트**: 기존 세션의 내용을 오늘 작업한 최신 창 목록과 메모로 덮어쓰기 기능 지원
- **비차단 예외 처리**: 파일이 이동되거나 삭제되어도 경고 알림 후 남은 정상 파일은 정상적으로 일괄 실행

## 2. 사용 방법

### 처음 실행

1. `WorkOnOff.exe`를 실행합니다.
2. 바탕화면에 **WorkOnOFF 업무 바로 이어하기** 바로가기가 자동으로 생성됩니다. 이후에는 이 바로가기 또는 `Ctrl + Shift + 1`로 프로그램을 실행할 수 있습니다. 프로그램이 이미 실행 중이면 기존 창이 앞으로 표시됩니다.

### 퇴근 전: 업무 저장

1. 현재 열려 있는 업무 목록에서 내일 다시 열 항목을 확인합니다.
   - Excel, Word, PowerPoint, 한글(HWP/HWPX), PDF, 텍스트 파일과 탐색기 폴더는 자동으로 수집됩니다.
   - 화면에 보이는 브라우저 창은 현재 선택된 탭 주소를 자동으로 수집합니다.
   - 자동으로 찾지 못한 웹페이지는 **[브라우저 URL 추가]**를 클릭한 뒤 주소를 붙여 넣어 추가합니다. `https://`를 생략해도 됩니다.
   - 누락된 문서나 폴더는 **[파일 추가]**, **[폴더 추가]**로 직접 넣을 수 있습니다.
2. 필요한 항목의 체크박스를 선택하고 업무 메모를 입력합니다.
3. **[다음날 하기]**를 클릭해 세션을 저장합니다.

### 다음 날: 업무 다시 열기

1. 바탕화면의 **WorkOnOFF 업무 바로 이어하기** 바로가기 또는 `WorkOnOff.exe`를 실행합니다.
2. 하단의 "최근 저장된 업무 목록"에서 전날 저장한 세션을 선택합니다.
3. **[업무 이어하기]**를 클릭하거나 세션을 더블클릭합니다.
4. 저장된 문서와 폴더가 연결 프로그램으로 열리고, 브라우저 주소는 저장 당시 브라우저를 우선 사용해 다시 열립니다.

## 3. 개발 및 빌드 환경
- **Target OS**: Windows 10 / Windows 11 (32비트 및 64비트 호환)
- **개발 언어**: C# (C# 5.0 호환 문법 적용)
- **프레임워크**: .NET Framework 4.8
- **컴파일러**: Windows 내장 C# 컴파일러 (`csc.exe`)
- **외부 종속성**: 0% (NuGet 패키지 및 외부 DLL 전혀 없음)

---

## 4. 빌드 방법
본 프로그램은 추가 SDK 설치나 인터넷 다운로드 없이, Windows에 기본 내장된 C# 컴파일러를 이용해 즉시 컴파일할 수 있습니다.

1. 프로젝트 소스가 위치한 폴더(`WorkOnOff`)로 이동합니다.
2. 명령 프롬프트(cmd)에서 `build.bat`을 실행합니다.
   ```cmd
   build.bat
   ```
3. 컴파일이 성공하면 동일 폴더에 약 40KB 크기의 단일 실행 파일인 `WorkOnOff.exe`가 생성됩니다.

---

## 5. 배포 방법
- 설치 과정이 필요 없는 **Portable(무설치)** 방식입니다.
- 생성된 `WorkOnOff.exe`와 안내를 위한 `README.txt`(또는 매뉴얼)를 단일 폴더에 넣어 사용자에게 USB 또는 내부망 공유 폴더를 통해 배포하면 됩니다.
- 사용자는 `WorkOnOff.exe`를 더블클릭하기만 하면 즉시 실행할 수 있습니다.
- **일반 사용자 권한(`asInvoker`)**으로 실행되어 설치나 관리자 권한 승인 창(UAC)이 뜨지 않습니다.
